# КЛЁН — сайт для GitHub Pages

Готовый статический сайт. Установка Node.js и сборка не нужны.

## Размещение

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки** в корень репозитория: index.html должен лежать непосредственно в корне, рядом с style.css, favicon.svg, slider-parts.pdf и папкой assets. Не загружайте ZIP вместо файлов.
3. Откройте Settings → Pages.
4. В Build and deployment выберите Deploy from a branch.
5. Выберите ветку main и папку / (root), затем Save.
6. Дождитесь публикации. Ссылка появится в Settings → Pages.

Сайт поддерживает размещение в подпапке репозитория: все локальные пути относительные. Файл .nojekyll отключает обработку Jekyll; если он скрыт при загрузке через браузер, остальные файлы всё равно работают.

## Файлы

- index.html — вся страница и тексты.
- style.css — оформление и адаптивная вёрстка.
- assets/assembly-reference.png — фотографии деталей и сборки.
- slider-parts.pdf — скачиваемая инструкция.
- favicon.svg — значок сайта.
- .nojekyll — настройка GitHub Pages.

Для предварительного просмотра откройте index.html в браузере. Все изображения, стили и PDF включены; ссылки на маркетплейсы требуют интернета.
